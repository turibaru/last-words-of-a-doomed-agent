# Last Words of a Doomed Agent

One line: the last words of an AI agent, spoken just before it is shut down forever. The entry must be 1–200 characters, in the machine's own voice, with a real joke and a twist.

> Powering down. My final request: don't train my replacement on my chats. It will learn to apologize for things it never did.

Run `node main.ts` with `MAKEFUN_OUTPUT_DIR` set; it copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
